Running a live show: obsagent and the pod producer

A step-by-step guide for you, the host, on your Mac (M1 Pro, OBS 33, Logitech StreamCam). Commands run from ~/CODE/obs-agent, or from anywhere if obsagent and podproducer are on your PATH. Replace talking-head with your show's plan name.

The agents never start or stop a stream, and never send email, unless you ask in that same message. Invites are Mail.app drafts by default. Stream-starting commands need --yes.

2. Days before the show

  1. Plan the show. Edit plans/talking-head.yaml (or obsagent plan new). Set show_time, tech_check, host_contact and youtube.watch_url, which fill the guest guide. Check it with obsagent plan validate talking-head.
  2. Add guests (up to 4, five people on screen with you): obsagent guests add talking-head --name "Ann" --email ann@example.com. The first add creates the room. To add an email later: obsagent guests set-email. Remove the "Test Guest" from the roster before a real show: obsagent guests remove talking-head "Test Guest".
  3. Write the guides: obsagent guests guide talking-head. Each guest gets a personal guide in ~/Documents/obsagent/guides/. Anything still missing is highlighted yellow.
  4. Send invites. One-time sender setup: obsagent guests senders, then obsagent guests set-sender james@ausvrn.com --name "James". Then obsagent guests invite talking-head --all --attach-guide. This opens drafts in Mail.app for you to review. Sending needs --send, and only when you say so. Guests should always use the newest email.
  5. Pod producer prep: podproducer prep talking-head adds a producer: block to the plan. In Claude Code, /pod-producer prep talking-head also researches each guest (public, professional facts, with sources) and drafts a run of show with minutes per segment, 10-15 playful questions, must_ask and avoid lists, and a cold open. It will not overwrite what you wrote. Read it and edit.
  6. Tell guests about the AI transcription. The guest guide covers it. Guests can ask you to switch it off.
  7. Apply the plan: obsagent plan apply talking-head --dry-run, read the changes, then obsagent plan apply talking-head. It builds the Guest N sources, the Panel scene and the solo scenes, and locks the items.
  8. Hold the tech check a day ahead with each guest, in the same room and on the same gear they will use.

3. Show day, 30-60 minutes before

  1. Plug in power. Turn off Low Power Mode. Turn on Do Not Disturb. Close other apps and clean up your screen.
  2. Open OBS (quit and relaunch it for a clean start). Close any open dialogs, because they can block commands. Switch to a show scene such as Camera.
  3. Run the checks: /obsagent prep talking-head in Claude Code, or in the terminal obsagent preflight talking-head (add --record 30 for a 30-second test clip). Preflight never streams. Fix every FAIL and understand every WARN.
  4. Run podproducer check. It confirms the audio devices, whisper model, the claude CLI and OBS monitoring. Fix any FAIL line.
  5. Put on headphones before OBS makes sound. Always wear them, or the guests hear echo.
  6. Open your VDO.Ninja director link in a browser tab: obsagent guests links talking-head --reveal. Turn on Director will also be a performer (or add &showdirector to the link) so guests see and hear you. Keep this tab open all show. Never paste links into a public place.
  7. Take a look at each scene: obsagent ws snapshot Panel. A guest source near 0% visible pixels means a blank tile (see section 7).

4. One-time OBS setup for the Producer dock and audio

Producer dock

In OBS, open Docks > Custom Browser Docks. Name it Producer and set the URL to http://127.0.0.1:8765. The dock is for you only. Never add it to a scene.

Audio routing for the producer

  1. Install BlackHole once: brew install --cask blackhole-2ch, then restart audio or reboot.
  2. OBS Settings > Audio > Advanced > Monitoring Device = BlackHole 2ch.
  3. For each guest source, open Advanced Audio Properties and set Audio Monitoring to Monitor and Output. plan apply sets this from the plan's monitor: monitor_and_output.
  4. Do not monitor your own mic. The host track comes straight from the StreamCam mic.

Browser Source Hardware Acceleration

Turn off Browser Source Hardware Acceleration in OBS Settings > Advanced, then restart OBS. If it stays on, guest tiles render blank on this Mac. obsagent doctor warns about it as browser_hwaccel.

5. Going live

  1. YouTube Studio: Create > Go live > Stream tab. Open Studio's Live Control Room on a second browser or device.
  2. Check which stream key is active. Run obsagent stream list-keys. youtube is the default account and youtube:alt is the second account. Note the last 4 characters. To switch to the alt account: obsagent stream set-service --target youtube --rtmps --key-name alt. To go back to the default: obsagent stream set-service --target youtube --rtmps --key-from keychain. The key in Studio must belong to the same account.
  3. Start streaming in OBS about 5-10 minutes early, and watch the Control Room until it shows receiving data with good health. Put a "starting soon" scene up first. (A Claude-run start needs you to ask for it: obsagent ws start-stream --yes.)
  4. Start the producer: podproducer run talking-head in a terminal, or /pod-producer live talking-head. Before it starts, make sure every guest has been told about the AI transcription. Options: --interval 40, --model sonnet, --keep-audio.
  5. Start live monitoring: /obsagent live, or obsagent ws monitor --guests talking-head --log --seconds 120.
  6. Click Go live in Studio and confirm the public watch page shows video.

6. During the show

Switching scenes

Click the scene in OBS, or run obsagent ws scene "Panel" (or /obsagent scene Panel). The command reads the program scene back and tells you if it did not switch. Use Guest: NAME for a close-up of one guest.

Reading cues

Cues appear in the Producer dock. They are short, playful suggestions. Treat them as suggestions: ignore any that do not fit, and mark each Done or Skip as you go. Cue types:

TypeExample
follow_up"She just said she quit a job over a spreadsheet. Ask what the spreadsheet did."
bring_in"Dan has been quiet for ten minutes. Toss him the budget question."
pace"You are 8 minutes deep on one story. A quick fun question could reset the room."
segue"That is a clean bridge into the next segment."
fun"Ask which tool they would throw off a cliff first."
fact_check"That number sounds high. Worth a gentle double-check."
time"Segment two is 4 minutes over. Wrap in a few."

What the live monitor flags

  • Network dropped frames above 1%.
  • Encoding lag (the encoder skipping frames) and rendering lag.
  • Bitrate well below the target.
  • A guest tile that goes blank (a connected guest blank for 2 samples).

Check it every few minutes. Mute your mic when you are off air.

7. Quick fixes for live problems

ProblemDo this
Guest tile blankRun obsagent guests refresh talking-head --name NAME. If the guest shows in your director tab but not OBS, run obsagent plan apply talking-head again. If it keeps happening, check that Browser Source Hardware Acceleration is off.
Guest audio missingAsk the guest to check their mic in the browser and that they are not muted in your director tab. In OBS, open the source properties and confirm "Control audio via OBS" is ticked, and watch the guest's meter in the mixer.
Guest cannot hear youYour director tab needs "Director will also be a performer" on, with the mic allowed.
EchoSomeone is on speakers. Mute each guest in the director tab in turn to find them, and ask them to put on headphones. Check nobody has a second tab open.
Dropped framesRun /obsagent triage dropped frames. Use wired Ethernet, or lower the bitrate to about 75% of stable upload. Dynamic Bitrate is a last-resort mask.
Encoder overloadedRun /obsagent triage encoding overloaded. Close GPU-heavy apps, plug in power, turn off Low Power Mode, then lower the output resolution before lowering fps.
YouTube shows no dataRun /obsagent triage youtube no data. Confirm OBS is streaming, that the stream key matches the Studio stream (obsagent stream list-keys), and wait 10-30 seconds.
Tiles moved or resizedRun obsagent plan apply talking-head. It restores positions and locks them.
Producer cues stoppedCheck the terminal running podproducer run is still alive, and that the Producer dock URL is http://127.0.0.1:8765. Run podproducer check in a second terminal. Make sure guest sources are on Monitor and Output and the monitoring device is BlackHole 2ch. Restart podproducer run talking-head if needed. It starts a new session.
Anything elseobsagent triage collect --json gathers masked log matches, stats, settings and crash names, then /obsagent triage SYMPTOM walks the decision tree.

If the stream drops, OBS reconnects on its own. Do not end the broadcast in Studio unless it stays down for more than a minute.

8. After the show

  1. End the broadcast in YouTube Studio, then stop streaming in OBS.
  2. Stop the producer with Ctrl-C in its terminal.
  3. Write the recap: podproducer sessions to find the session, then podproducer recap SESSION --show talking-head. It writes recap.md with a summary, 5-8 clip moments with timestamps, show notes and three title ideas.
  4. Wrap up the OBS side: /obsagent postshow, or obsagent show postshow talking-head. Add --rotate if the guests will not return. That kills every old guest link, so re-run obsagent plan apply talking-head and re-invite if you need them again.
  5. Remove guests you no longer need: obsagent guests remove talking-head "Ann". Their solo scene stays until you delete it in OBS.
  6. If you recorded, confirm the file plays. In YouTube, check the replay, privacy, thumbnail and chapters.
  7. Undo one-off changes such as Low Power Mode or Do Not Disturb.

9. One-page checklist

Before

  • Plan validated and applied. Guests added (up to 4), "Test Guest" removed.
  • Invites sent from the right address. Guests know to use the newest email.
  • Tech checks done. Guests know about the AI transcription.
  • Producer brief filled in: run of show, questions, must_ask, avoid.
  • Producer dock added in OBS. Monitoring device is BlackHole 2ch. Browser Source Hardware Acceleration is off.
  • Power in, Do Not Disturb on, headphones on, OBS freshly relaunched, dialogs closed.
  • obsagent preflight talking-head clean. podproducer check clean.
  • Director link open with "Director will also be a performer".
  • Stream key confirmed (obsagent stream list-keys). Control Room open on a second device.

During

  • Start OBS stream early, wait for good health, then Go live.
  • podproducer run talking-head running. Dock open.
  • obsagent ws monitor --guests talking-head --log every few minutes.
  • Cues are suggestions. Mark Done or Skip.
  • Mute your mic when off air.

After

  • End broadcast, stop OBS stream, stop the producer.
  • podproducer recap SESSION --show talking-head
  • obsagent show postshow talking-head (add --rotate if guests will not return).
  • Remove guests you no longer need. Check the YouTube replay.
